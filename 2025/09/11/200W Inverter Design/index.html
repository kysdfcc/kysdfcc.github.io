200W Inverter Design

1. 简介

本文设计了一种工频逆变器系统，设计功率200W，效率90%，输入电压为 48V 直流，输出电压为 24V 50Hz 交流电。逆变器通过 24/220V 工频变压器并入电网。系统控制核心采用德州仪器（TI）C2000 系列的 TMS320F280025 数字信号处理器，实现逆变器的驱动控制、并网同步以及相关保护功能。

2. 参数设计

设计功率：P = 500W

交流电周期：T = 0.02s

交流电频率：f = 50Hz

开关频率：fsw = 50kHz

效率：η = 90%

输入电压：Udc = 48V

输出电压有效值：Uac = 24V

输入电流：$I_{in} = \frac{P}{U_{dc}/η} = 3.75A$

输出电流有效值：$I_{o} = \frac{P}{U_{ac}} = 8.33A$

输入等效电阻：$R_{dc} = \frac{U_{dc}^2}{P / η} = \frac{48^2}{200 / 0.9} = 10.37Ω$

输出等效电阻：$R_{ac} = \frac{U_{ac}^2}{P} = \frac{24^2}{200} = 2.88Ω$

直流侧输入电容：$C_{dc} = \frac{(6 \sim 8)T}{2R_{dc}} = \frac{(6 \sim 8)\times0.02}{2 \times 10.37} = 5787 \sim 7716 μF$

开关管承受最大电流：$I_{mos_{max}} = \frac{\sqrt{2} \times P}{U_{ac}} = \frac{\sqrt{2} \times 200}{24} = 11.79A$

允许最大脉动电流：$ΔI_{max} = 20\% \times \sqrt{2} \times I_{o} = 20\% \times 8.33 = 2.36A$

滤波电感最大值：$L \leq \frac{5 \% \times U_{ac}}{2 \pi f \times I_{o}} = \frac{5\% \times 24}{2 \pi \times 50 \times 8.33} = 458.55μH$

滤波电感最小值：$L \geq \frac{U_{dc}}{4 \times ΔI_{max} \times f_{sw}} = \frac{48}{4 \times 2.36 \times 50000} = 101.69μH$

滤波电容最大值：$C \leq \frac{5 \% \times I_{o}}{2 \pi f \times U_{ac}} = \frac{5\% \times 8.33}{2 \pi \times 50 \times 24} = 55.24μF$

直流侧输入电容选用两个3300μF/100V电容并联

选择NMOS型号为 NCEP0178AK VDS = 100V，$I_{D} = 78A $

选择滤波电感：L = 330μH

选择滤波电容：C = 4.7μF

截止频率：$f_c = \frac{1}{2\pi\sqrt{LC}} = \frac{1}{2\pi\sqrt{330 \times 10^{-6} \times 4.7 \times 10^{-6}}} = 4041Hz$，满足要求
